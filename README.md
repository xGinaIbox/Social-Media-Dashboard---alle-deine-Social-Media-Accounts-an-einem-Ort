# Simple Social Dashboard

Eine einfache statische Website, um mehrere Social-Media-Accounts auf einer Seite zu verwalten.

## Dateien

- `index.html` – Die Hauptseite
- `styles.css` – Styling für das Dashboard
- `app.js` – Lokaler Speicher und Anzeige-Logik

## Nutzung

1. Öffne `index.html` im Browser.
2. Füge über das Formular deine Social-Media-URLs hinzu.
3. Klicke auf einen Link, um das jeweilige Profil in einem neuen Tab zu öffnen.
